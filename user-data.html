Overview / User Data Requests

Government Requests for User Information

Legal process requests from governments to disclose Google user data. Search warrants, subpoenas, and court orders — per country.

Interactive — No Bulk CSV
Data source: Google Transparency Report — User Data. Figures reflect the interactive report.

Key Findings

  • US accounts for approximately 50% of all requests by volume.
  • Google discloses data in 70–80% of cases with valid legal process.
  • Emergency disclosure requests have risen sharply since 2019.
  • Search warrants carry the highest compliance rate; national security letters are disclosed only in aggregate.
  • Total global requests grew from ~12,000 (2010) to over 60,000 per half-year period.
